`rulepack.json` は AI の記憶をパッキングするためのマニフェストです。パックの名前、
ライセンス、公開範囲、配布する Markdown memories、そして consumer 側では依存する
パックを宣言します。`package.json` と同じく、プロジェクト直下に置きます。

<Callout title="置き場所">
つねにリポジトリ直下：`/rulepack.json`。CLI はカレントディレクトリから解決するので、
どのコマンドもルート直下のマニフェストを前提とします。
</Callout>

## package.json から来た人へ

`package.json` を書いたことがあれば、形はすぐ分かります。違うのは中身です。
`package.json` はコードを、`rulepack.json` は AI エージェントが読む Markdown memories
を配布します。

| `package.json` | `rulepack.json` |
| --- | --- |
| JavaScript / TS コードを配布 | Markdown memories を配布 |
| `name`・`version` | `name`・`version` *(意味は同一)* |
| `license` | `license` *(公開パックでは必須)* |
| npm の公開範囲 / access | `visibility`: `public`・`private`・`pay` |
| `dependencies` | `dependencies` *(他の rule packs)* |
| 同梱する `files` | 同梱する `files` |
| `main` / `exports` のエントリ | `memories` マップ：AI が読むファイル |

## JSON は書けない？ エージェントに書かせよう

```text title="エージェントに貼り付け"
このプロジェクトに rulepack.json をセットアップして。

rulepack.json は package.json に似ているけど、コードの代わりに、このリポジトリの
AI memory ファイル（AGENTS.md / CLAUDE.md / .cursor/rules / .clinerules /
.windsurfrules / GEMINI.md / Copilot instructions / custom Markdown docs）を、
再利用・バージョン管理できる 1 つのパックにまとめるもの。

お願い:
1. リポジトリを調べて、すでに存在する AI memory ファイルを全部挙げて。
2. プロジェクト直下に rulepack.json を作成して、次を含めて:
   - "name": "@<私のscope>/<短いパック名>"（scope は私に聞いて）
   - "version": "0.1.0"
   - "license": "MIT"（別のライセンスを選ぶなら聞いて）
   - "visibility": "public"（private / pay にするなら聞いて）
   - "description": これらの memories が AI に何を助けるかを 1 行で
   - "memories": 既存ファイルを標準キー agents, claude, cursor, cline,
     windsurf, gemini, copilot に対応づけて。その他の Markdown は "custom"
     に path と任意の description/readWhen/tags 付きで入れて。
   - "files": rulepack.json, LICENSE, README.md, すべての memory path を含めて。
3. 作成したファイルを見せて、各フィールドをやさしい言葉で説明して。

参考: https://rulepack.lyrra.net/rulepack.json
```

## 例

```json title="rulepack.json"
{
  "name": "@ichi/nextjs",
  "version": "1.4.0",
  "description": "Strict Next.js rules for Claude Code + Cursor",
  "license": "MIT",
  "visibility": "public",
  "keywords": ["nextjs", "typescript", "strict"],
  "memories": {
    "agents": "AGENTS.md",
    "claude": "CLAUDE.md",
    "cursor": ".cursor/rules/main.mdc",
    "custom": {
      "launch-plan": {
        "path": "docs/launch-plan.md",
        "description": "Launch and social media plan",
        "readWhen": "when planning launch posts or growth strategy",
        "priority": "normal",
        "tags": ["marketing", "launch"]
      }
    }
  },
  "files": ["rulepack.json", "README.md", "LICENSE", "AGENTS.md", "CLAUDE.md", ".cursor/rules/**", "docs/launch-plan.md"],
  "dependencies": {
    "@rulepack/typescript": "^0.1.0"
  }
}
```

## フィールド

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `name` \* | `string` | `@scope/name`。小文字・数字・内部のハイフン。scope は自分が所有するもの。 |
| `version` \* | `string` | Semver。公開済みバージョンは不変 — リリースごとに上げる。 |
| `license` \* | `string` | SPDX 識別子（`MIT`・`Apache-2.0`）または `UNLICENSED`。 |
| `visibility` \* | `"public" \| "private" \| "pay"` | レジストリ側の access policy。配布形式は 3 種すべて同じ。 |
| `description` | `string` | 1 行、280 文字以内。検索結果とパックページに表示。 |
| `author` | `string` | 任意の author 表示名。 |
| `homepage` | `string` | 任意の HTTP(S) URL。 |
| `keywords` | `string[]` | 発見用タグ、最大 20 個。 |
| `memories` \* | `object` | 標準 memory paths と任意の `custom` project memories。最低 1 つ必須。 |
| `files` | `string[]` | 公開 tarball のグロブパターン。CLI は `rulepack.json` と宣言済み memory path を常に含める。 |
| `dependencies` | `object` | consumer 側。`@scope/name` → semver 範囲。`rulepack add` が記録。 |

<small>\* 公開パックでは必須。</small>

## visibility

| 値 | アクセス |
| --- | --- |
| `public` | 誰でも metadata / memory files を閲覧でき、インストールできる。 |
| `private` | 許可されたユーザー / team だけが閲覧・インストールできる。 |
| `pay` | metadata と購入ページは公開可能。memory files と tarball は購入後のみ。 |

## memories マップ

| キー | Memory | 既定パス |
| --- | --- | --- |
| `agents` | AGENTS.md | `AGENTS.md` |
| `claude` | Claude Code | `CLAUDE.md` |
| `cursor` | Cursor | `.cursor/rules/main.mdc` |
| `cline` | Cline | `.clinerules` |
| `windsurf` | Windsurf | `.windsurfrules` |
| `gemini` | Gemini CLI | `GEMINI.md` |
| `copilot` | GitHub Copilot | `.github/copilot-instructions.md` |

`memories.custom` は、計画、引き継ぎ、設計メモ、launch docs、調査メモなど、特定の
エージェントに限らない Markdown のための場所です。

## author と consumer

**author** マニフェストは `name`・`version`・`license`・`visibility`・最低 1 つの
`memories` エントリが必須です。**consumer** マニフェストは `dependencies` だけでよく、
それは `rulepack add` が維持します。

```json title="rulepack.json"
{
  "dependencies": {
    "@ichi/nextjs": "^1.4.0"
  }
}
```
