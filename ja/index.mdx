title: 概要
description: rulepack とは何か、そして各要素がどう組み合わさるか。
---

rulepack は、AI memory ファイルのためのレジストリと CLI です。memories を一度書いて
プロジェクト直下の 1 つの `rulepack.json` に記述すれば、
あらゆるエージェント — Claude Code・Cursor・Gemini CLI・GitHub Copilot・Cline・Windsurf、
そして AGENTS.md を読む 20 以上のツール — に配布できます。

AI memory のための npm だと考えてください。**パック**は、エージェントが読む
Markdown files（`AGENTS.md`、`CLAUDE.md`、`.cursor/rules/main.mdc` など）をまとめたもので、
不変の semver でバージョン管理され、1 コマンドでどのプロジェクトにもインストールできます。

## プロジェクトの形

`rulepack.json` はリポジトリのルート、`package.json` のすぐ隣に置きます — 他の
あらゆるエコシステムがマニフェストを置くのと同じ場所です。これは意図的で、
すぐに馴染めるようにしてあります。

```text title="your-project/"
.
├── rulepack.json          # マニフェスト — ルート直下
├── package.json
├── AGENTS.md
├── CLAUDE.md
└── .cursor/
    └── rules/
        └── main.mdc
```

<Callout title="ルート配置が規約です">
`rulepack.json` はプロジェクト直下に置いてください。npm が `package.json` を探すのと
同じく、ツールはカレントディレクトリから解決します。`rulepack publish` も
`rulepack add` もルート直下のマニフェストを前提とします。
</Callout>

## 数秒でインストール

```bash title="terminal"
npx rulepack add nextjs
```

これでレジストリからパックを解決し、SHA-256 を検証して、memory ファイルを
プロジェクトに書き込みます。結果はあなたの `rulepack.json` に記録されます。

## 公開・非公開・有料

パックの `visibility` が、ファイルを読める相手を決めます — **public**（誰でも）、
**private**（自分の scope のみ）、**pay**（metadata と README は公開のまま、
ファイルは購入で解放）。public と private は今すぐ利用可能、有料の決済は近日対応です。
[公開範囲とアクセス](/docs/rulepack-json#公開範囲とアクセス) を参照。

## 記事

パックに加えて、rulepack には **記事** があります — AI の操縦術やプレイブックです。
記事は無料、または有料のゲートされた本文付きで公開でき、裏側の memory パックを
紐付ければ、読者は読み物から `rulepack add` までワンステップで進めます。
[記事](/docs/articles) を参照。
