_最終更新: 2026-05-31_

本プライバシーポリシーは、あなたが **rulepack**（ウェブサイト・レジストリ API・CLI）を利用する際に
**Lyrra**（以下「当社」）が個人データをどう扱うかを説明します。当社は本サービスの動作に必要なものだけを
収集することを目指します。

## 収集する情報

**サインイン時（GitHub OAuth）:**

- GitHub から提供される **login（ユーザー名）**・**メールアドレス**・**表示名**・**アバター URL**。
- セッション、および CLI 用に発行する API トークン（平文ではなくハッシュで保存）。
- 設定（UI 言語・テーマ）と取得した scope。

**公開・閲覧時:**

- 公開したパック —— 名前・バージョン・メタデータ・ファイル内容 —— これらは **公開** されます。
- パックごとのダウンロード数・閲覧数の集計イベント（fire-and-forget）。広告プロファイルは作成しません。

**自動的に:**

- セキュリティ・不正防止・デバッグのための標準的なサーバーログ（IP アドレス・User-Agent・タイムスタンプ）。

第三者の広告・解析トラッカーは **使用しません**。

## 利用目的

- 本サービスの運営: 認証、パックの帰属表示と配信、検索、ダウンロード/閲覧数の表示。
- 本サービスの保護: 不正の検知・防止、法的義務の遵守。

## ホスティングと第三者

本サービスは **自己ホスト** しています。データベースと検索インデックスは当社自身のインフラ上で動作し、
第三者サービスではなく、外部に公開もしていません。実際に関与する第三者は次のとおりです：

- **GitHub** —— GitHub でサインインし、GitHub からプロフィール情報が提供されます。GitHub の利用は
  GitHub 自身のポリシーに従います。
- **ホスティング / ネットワーク事業者** —— インフラを動かすサーバーホスト、および **Cloudflare**
  （ネットワーク/CDN）が、本サービスの提供に必要な範囲でデータを処理します。

公開パックの内容は設計上すべての人に見えます。個人データの販売や第三者の広告トラッカーの利用はありません。

## 保持期間

- アカウントデータはアカウントが存在する間保持します。
- 公開済みバージョンは **不変かつ公開** であり、他者が依存している可能性があるため、
  アカウント変更後も利用可能なまま残ることがあります。
- ログはセキュリティ・運用のため限られた期間保持します。

## あなたの選択肢と権利

- **設定** で名前・言語・テーマを変更でき、scope の改名・管理もできます。
- **設定 → トークン** で CLI トークンをいつでも失効できます。
- 個人アカウントデータへのアクセス・訂正・削除は当社へご連絡ください。
  ただし **公開済みバージョンは原則として取り消せません**（レジストリの不変性に利用者が依拠しているため）。
  バージョンに削除すべきデータが含まれる場合はご連絡ください。

## 海外の利用者

本サービスは **日本** から運営されており、利用にあたりデータが日本で処理される場合があります。
現地法（GDPR 等）が追加の権利を認める場合、適用される請求に対応します。

## 子どもについて

本サービスは、各地域でデータ処理に同意できる年齢未満の子どもを対象としていません。

## 変更

本ポリシーを改定することがあります。重要な変更は「最終更新」日とともに本ページに反映します。
