`rulepack` CLI は `npx rulepack <command>` でインストール不要で実行でき、グローバル
インストールも可能です。英語と日本語に対応し、初回実行時にロケールを判定します。

## add

パックを現在のプロジェクトにインストールします。ダウンロードして SHA-256 を検証し、
memory ファイルを書き込みます。

```bash title="terminal"
rulepack add @ichi/nextjs
rulepack add nextjs                 # house パックは scope 無しの名前でインストール
rulepack add @ichi/pack --force     # 既存ファイルを確認なしで上書き
```

## update

インストール済みパックをレジストリの新しいバージョンに更新します。デフォルトは宣言された
依存範囲内の最大バージョンを選び、`--latest` で範囲を無視して最新へ。SHA-256 を検証し、
ローカルファイルを上書きする前に確認します（`--force` で確認をスキップ）。

```bash title="terminal"
rulepack update                     # 導入済み全パック
rulepack update @ichi/nextjs        # 単一パック
rulepack update --latest            # 宣言レンジを無視
```

## init

カレントディレクトリに `rulepack.json` を雛形生成します。既存の memory ファイルを
検出し、含めるものを尋ねます。

```bash title="terminal"
rulepack init
```

## link

カレントプロジェクト内の既存 Markdown memory ファイルを走査し、`rulepack.json` に
紐付けます。慣例パス（`CLAUDE.md`・`AGENTS.md`・`.cursor/rules/…`）は標準 memory に
自動分類し、その他の Markdown は編集可能なキー付きの custom memory として提示します。

```bash title="terminal"
rulepack link
```

## memory add

`rulepack.json` に memory を 1 つ追加します ― 標準の agent キー、または custom memory
（任意の description・readWhen・priority・tags 付き）。

```bash title="terminal"
rulepack memory add
```

## publish

宣言したファイルをまとめてレジストリに公開します。ログインと取得済みの scope が必要です。
バージョンは不変です。

```bash title="terminal"
rulepack publish
```

## login

レジストリで認証します。ブラウザを開いて CLI セッションを承認すると、トークンが
`~/.rulepackrc`（chmod 0600）に保存されます。CI では代わりに `RULEPACK_TOKEN` を設定します。

```bash title="terminal"
rulepack login
```

## search

レジストリのパックを名前・scope・キーワードで検索します。

```bash title="terminal"
rulepack search nextjs
```

## whoami

現在ログイン中のユーザーと、有効なレジストリを表示します。

```bash title="terminal"
rulepack whoami
```

## logout

ローカルに保存された認証情報を削除します。

```bash title="terminal"
rulepack logout
```
